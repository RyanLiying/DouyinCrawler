MediaCrawler 配置与运行工具

面向抖音非遗研究的可视化配置。填写表单后，可直接在页面中启动爬虫，无需覆盖原配置文件。

使用说明

  1. 在「字段选择」Tab 中勾选需要额外采集的字段。
  2. 在「基础配置」中调整爬虫参数。默认已填好非遗关键词。
  3. 右侧会实时预览生成的 base_config.py 和 dy_config.py。
  4. 点击「启动爬虫」，后端会创建临时配置文件并运行 MediaCrawler。
  5. 运行日志会实时显示在页面底部的终端区域。
  6. 如需停止，点击「停止爬虫」。

提示：首次使用前请确保已启动后端服务（python server.py），并开启 Chrome 远程调试。
